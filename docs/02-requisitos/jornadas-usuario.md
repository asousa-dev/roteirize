# Jornadas do usuário

[← Voltar ao índice da documentação](../README.md)

## 9.1 Primeira viagem

1. O visitante cria uma conta.
2. O usuário inicia uma nova viagem.
3. Informa cidade e datas.
4. Define o endereço da hospedagem.
5. Escolhe horários diários e ritmo.
6. Pesquisa e adiciona atrações.
7. Ajusta prioridades e duração.
8. Informa reservas fixas, se existirem.
9. Solicita a geração.
10. Analisa o roteiro, o mapa e os alertas.
11. Move ou bloqueia atividades.
12. Solicita um recálculo.
13. Salva a versão final.

## 9.2 Alteração de uma atração

1. O usuário abre uma viagem existente.
2. Seleciona uma atração.
3. Altera duração, prioridade ou disponibilidade.
4. O sistema marca o roteiro como desatualizado.
5. O usuário escolhe recalcular apenas o dia ou todo o roteiro.
6. O sistema apresenta as mudanças.
7. Os itens bloqueados permanecem no lugar.

## 9.3 Conflito de reserva

1. O usuário informa uma visita às 15h.
2. O deslocamento anterior faria a chegada ocorrer às 15h20.
3. O sistema não ignora o problema.
4. A programação recebe um alerta de conflito.
5. O sistema sugere remover, encurtar ou mover a atividade anterior.

## 9.4 Atração que não cabe

1. O usuário adiciona mais atividades do que o período permite.
2. O sistema prioriza as atrações mais importantes.
3. As atrações restantes aparecem em “Não planejadas”.
4. Cada item recebe uma justificativa.
5. O usuário pode aumentar um dia, reduzir durações ou substituir atividades.
