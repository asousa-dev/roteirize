# Glossário

[← Voltar ao índice da documentação](../README.md)

| Termo | Definição |
|---|---|
| Atração | Lugar que o usuário deseja visitar em uma viagem |
| Base | Hospedagem ou ponto usado como origem e possível retorno diário |
| Compromisso fixo | Atividade com data e horário obrigatórios |
| Conflito | Condição que reduz ou impede a viabilidade do roteiro |
| Dia da viagem | Data planejável entre início e fim |
| Geração | Execução do algoritmo que produz uma versão do roteiro |
| Item bloqueado | Atividade que o algoritmo não pode mover |
| Janela de disponibilidade | Intervalo em que a visita pode ocorrer |
| Lugar | Entidade geográfica independente da viagem |
| Matriz de deslocamentos | Tempos e distâncias entre pares de pontos |
| Não planejada | Atração selecionada que não foi encaixada |
| Restrição flexível | Preferência que pode ser violada com penalidade |
| Restrição rígida | Condição que deve ser respeitada ou gerar conflito |
| Roteiro | Programação de atividades distribuídas nos dias |
| TripPlace | Configuração de uma atração dentro de uma viagem específica |
